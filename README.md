# TOKI 道場

GMOコインの**リアルタイムの板と約定**を使って、仮想の売買でデイトレードを練習するアプリです。
スマホのブラウザで開くだけで使えます。

- **実際の注文は一切出しません。** APIキーも使いません（非公開の API を呼ぶコードがありません）
- 取引・チャートの足・設定は**その端末のブラウザの中だけ**に保存します。どこにも送りません
- つなぐ先は GMO の公開配信 `wss://api.coin.z.com/ws/public/v1` と、過去の足の中継（`relay/`・Cloudflare Workers）だけです（CSP で固定）

## できること

- 8銘柄（BTC・ETH・XRP・SOL・DOGE・XLM・ADA・BCH）の**現物**と**レバレッジ（2倍）**を切り替え
- チャートの足の長さは **Tick**（約定ごとの値段の線。GMO の Tick と同じ見え方）・**10T・30T・100T**（N 約定で1本）・1分・5分・15分・1時間、MA 20/75。**開いた直後から約120本の過去の足**を出す（中継 `relay/` 経由。中継が無い・落ちているときは、開いている間の約定から足を作る）
- 板（10/20段）と約定の流れ。板の値段を押すと注文の値段に入る
- 成行・指値・逆指値。レバの建玉に損切り・利確（片方が約定したらもう片方は取消）
- 振り返り: 勝率・損益・最大DD・時間帯別、**偶然との比較**（同じ取引を無作為な時刻に入った200通りと比べる）、メモ、CSV/JSON の書き出し
- 仮想資金は 3万（既定）・10万・30万・100万円から選べる

## 本物に合わせていること

- 最小数量・数量の刻み・値段の刻み・手数料（Maker のリベートを含む。円未満は GMO と同じ向きに丸める）
- 成行は**板を上から食う**（厚みが足りなければ一部だけ約定）
- 注文から約定の判定まで**通信の遅れ**を置く（既定 300ms）
- レバレッジ: 建玉管理料（UTC 20時に1日 0.04%）・証拠金維持率 75% を割ると強制決済
- 板が5秒より古い（切断・メンテナンス）ときは注文できない
- アプリを閉じていた間の値動きは分からないので、30秒を超える空白があると待機中の注文を取り消す

**本物と違うところ**: 練習の注文は本物の板を食わないので、自分の注文で値段が動きません。
大きな数量では本物より有利に出ます。

## 使い方

公開ページ https://somanakahashi-ops.github.io/toki-dojo/ を開くだけです。

**ホーム画面に追加**（アプリのように全画面で開ける）
- iPhone の Safari: 下の共有ボタン（□に↑）→「ホーム画面に追加」
- iPhone の Chrome: アドレスバー右の共有ボタン（□に↑）→ 一覧を下へ →「ホーム画面に追加」（「…」のメニューには無い。iOS 16.4 以上）
- Android の Chrome: 右上の「⋮」→「ホーム画面に追加」
設計は `docs/`（01 基本設計 → 02 外部設計 → 03 内部設計 → 04 整合性レビュー → 05 詳細設計）にあります。

## 開発

ビルドはありません。静的なファイルをそのまま配ります。

```sh
npm test                                   # 約定の規約・口座・配信・構造のテスト（Node 22）
NODE_USE_ENV_PROXY=1 node test/smoke.e2e.mjs out/   # 本物の配信で通し（Playwright が要る）
```

構造のテストは、`/private`・APIキー・`innerHTML` のような危ない書き方・外部のスクリプトが
入り込んだら落ちます。
