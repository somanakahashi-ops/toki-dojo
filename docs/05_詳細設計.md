## 2. 約定の規約（`js/engine.js`・すべて純粋な関数）

| 関数 | 入力 → 出力 | 規約 |
|---|---|---|
| `decimals(step)` | 刻み → 小数の桁数 | `"0.00001"` → 5 |
| `floorStep(x, step)` | 数 → 刻みに切り下げた数 | `Math.floor(x/step + 1e-9) * step` を桁数で丸める |
| `roundTick(p, tick, dir)` | 値段 → 刻みの値段 | dir=down は切り下げ、up は切り上げ |
| `feeYen(notional, rate)` | 金額・率 → 手数料（円） | rate>0: `ceil(notional×rate − 1e-9)`（切り上げ）。rate<0: `−floor(notional×|rate| + 1e-9)`（リベートは切り捨て、負の手数料）。0: 0 |
| `sweep(levels, size, {fillRemainder})` | 板の段（良い順）・数量 → `{filled, avgPrice, notional, remainder, levelsUsed, worst}` | 上から順に食う。足りなければ remainder>0。**fillRemainder=true（決済）なら残りを最後の段の値段で約定**（04 R-4） |
| `sweepLimit(levels, size, limit, side)` | 指値で今すぐ約定できるぶん | 買いは 値段≤指値 の段だけ、売りは 値段≥指値 の段だけ食う |
| `limitHit(side, limit, {trade, bestBid, bestAsk})` | → bool | 買い: `trade<limit` または `bestAsk<limit`。売り: `trade>limit` または `bestBid>limit`。等しいときは約定しない（04 R-3） |
| `stopHit(side, stop, trade)` | → bool | 買い: `trade≥stop`。売り: `trade≤stop`（最終約定で判定。04 R-11） |
| `unrealized(pos, bestBid, bestAsk)` | → 円 | 買い建て: `(bestBid−entry)×size`。売り建て: `(entry−bestAsk)×size`（決済する側の気配） |
| `requiredMargin(positions)` | → 円 | `Σ entryPrice×size / LEVERAGE` |
| `marginRatio(cash, locked, unreal, required)` | → 比 | required=0 なら ∞。`(cash + locked + unreal)/required`（04 R-6） |
| `carryCount(fromMs, toMs, hour)` | → 回数 | (from, to] に含まれる UTC `hour:00` の数 |
| `carryYen(entryNotional)` | → 円 | `ceil(entryNotional × CARRY_RATE)` |
| `pnlSpotClose(size, price, fee, avgCost)` | → 円 | `size×price − fee − avgCost×size` |
| `pnlLevClose(pos, size, price, fee)` | → 円 | `dir×(price−entry)×size − fee − 按分した建てた時の手数料 − 按分した建玉管理料`（dir: 買い建て+1・売り建て−1） |

## 3. 口座（`js/account.js`）

- `place(input, now)`
  - 検査の順: ①値が新しい（`market.isFresh`）②数量≥最小・刻みに切り下げ・≤最大 ③銘柄数の上限（04 R-8）④現金・保有・証拠金の余力（押さえた分を引く）
  - 通れば `status=pending, executeAt=now+LATENCY`。成行・指値・逆指値のどれでも、受け付けた時点で余力を押さえる（04 R-5）
- `step(now)`: pending で executeAt≤now のものを処理
  - 値が古ければ拒否（04 R-12）
  - 成行: `sweep`。新規で remainder>0 なら残りは取り消して知らせる。決済は fillRemainder
  - 指値: `sweepLimit` で今すぐのぶん（Taker）、残りは working
  - 逆指値: working
- `onTrade(inst, price, t)`
  - working の逆指値で `stopHit` → 成行の注文に変えて遅れを置く
  - working の指値で `limitHit` → 指値の値段で Maker 約定
- `onBook(inst)`
  - working の指値で `limitHit`（気配の逆転）→ 約定
  - レバの維持率 < 0.75 → 全建玉を成行で決済（fillRemainder）
- `onCarry(serverNow)`: `carryCount(lastCarryAt, serverNow)` 回ぶん、持っている建玉の `carryYen` を現金から引き、建玉ごとに累計する
- `onGap(serverNow)`: working の注文をすべて取消（理由: 空白）。onCarry で追いつく。維持率を判定
- 約定の反映
  - 現物の買い: 現金 −(金額＋手数料)、保有 qty/cost を増やす（cost は手数料込み）。保有が0からなら openedAt=約定時刻
  - 現物の売り: 現金 +(金額−手数料)、平均取得で cost を減らす。取引を1件記録
  - レバの新規: 現金 −(手数料＋必要証拠金)（locked に移す）。建玉を追加。損切り・利確があれば OCO の組で working
  - レバの決済: locked を戻し、現金 ±損益。取引を1件記録。一部なら損切り・利確の数量を合わせる（04 R-7）。OCO の相手を取消
- 値段の丸め: 指値・逆指値の値段は値段の刻みに丸める（買いは切り下げ、売りは切り上げ）

## 4. 振り返り（`js/review.js`）

- `stats(trades, initialCash)`
  - 件数・勝率（損益>0）・合計・平均の勝ち／負け・手数料の合計・建玉管理料の合計
  - 最大DD: 確定損益の累計で、円と「初期資金に対する%」（04 R-9）
  - 日本時間の時間帯別
- `randomCompare(trades, quotes, {draws, seed})`
  - quotes は銘柄ごとに1分ごとの `{t,bid,ask}` を時刻順で持つ
  - 取引ごとに保有 h 分（最低1）を決め、**t から t+h まで1分も欠けない**開始点の候補を集める。無ければ比較から外す（04 R-2）
  - 1回の偶然の取引
    - 建値: 買いなら ask、売りなら bid（Taker の脚）。Maker の脚は仲値
    - 決済値: 逆の気配（Maker なら仲値）
    - 手数料: 同じ率で `feeYen`
    - 建玉管理料: `carryCount` × `carryYen`
  - 各回の合計を draws 回作る（シードつきの乱数 mulberry32）
  - 返すもの: `{status, userTotal, percentile, included, excluded, median, p5, p95}`
    - percentile は「偶然の合計 < 利用者の合計」の割合
    - included < 20 なら status="insufficient"

## 5. 配信（`js/ws.js`・`js/validate.js`・`js/market.js`）

- 接続: `new WebSocket(URL)`
  - onopen で購読の列を流し直す
  - onclose で 1→2→4→…→30 秒の待ちで再接続
- 購読の列: 1.1秒おきに1件送る。重複は入れない
- `validate.message(raw)`
  - 文字列かつ ≤256KB → JSON.parse（失敗は捨てる）
  - channel と symbol を確かめる
  - 数値は `Number()` で有限・>0（size は ≥0）
  - timestamp は `Date.parse` で有限
  - 板は各段を検査し、段数を ≤100 に切る
  - 捨てた数を数えて設定画面に出す
- `market.update(msg)`: 銘柄ごとに板・気配・最終約定・受け取った時刻（端末）とサーバーの時刻を更新
- `market.isFresh(inst, now)`: 最後の板の受け取りから5秒以内

## 6. 足と気配（`js/candles.js`）

- `onTrade(inst, price, size, t)`: `t` の分の1分足を更新。分が変わったら前の足を保存（store）
- `onBook(inst, bid, ask, t)`: その分の最後の気配を持ち、分が変わったら保存
- `series(inst, frame)`: 1分足を frame（1・5・15・60分）に束ねた配列（時刻昇順）。**欠けた分は作らない**（チャートでは空白）
- 起動時に store から直近7日を読み、7日より古いものは消す
